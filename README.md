# HKUST 空调自动循环插件

在 HKUST 学校空调控制页面上，按你设定的分钟数交替开机和关机。支持运行中修改时长、有限超时恢复和本地错误报告。

**当前版本：1.1.22 · 中文界面 · 非学校官方项目**

## 安装：下载、解压、加载

1. 下载上方 ZIP，将它完整解压到一个以后不会删除或移动的文件夹。
2. 找到解压后的 **`HKUST-AC-Cycle` 文件夹**，里面应能直接看到 `manifest.json`。
3. 在 Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
4. 开启“开发人员模式／开发者模式”，点击“加载解压缩的扩展／加载已解压的扩展程序”（Load unpacked）。
5. 选择上面的 **`HKUST-AC-Cycle` 文件夹**，不要选择 ZIP 文件或外层目录。
6. 打开[学校空调主页](https://w5.ab.ust.hk/njggt/app/home)，自行登录；如果页面已经打开，刷新一次。空调状态卡片中会出现“自动循环”面板。

这套操作对应浏览器官方的本地加载方式：[Edge 说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)、[Chrome 说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。插件的操作面板在学校网页中，工具栏图标没有单独的控制弹窗。

## 如何使用

1. 确认学校页面显示的实际空调状态，并取消学校原有的定时关闭设置，避免冲突。
2. 填写“开机”和“关机”分钟数，范围均为 **1–1440 的整数**；首次默认各 10 分钟。
3. 点击“开始循环”。插件先核验学校定时器和实际状态，再从开机阶段开始；已经开机时不会重复发送开机指令。
4. 运行中可编辑时长，点击“应用修改”才生效；新时长影响当前阶段及后续循环。
5. 点击“停止循环”结束调度。**停止循环不会替你关机**，如需关机，请使用学校页面的原生开关并确认结果。

例如：开机设为 10 分钟，已经运行 7 分钟；改成 12 分钟后还剩 5 分钟。改成 5 分钟则立即核验并尝试切换。已经过去的时间不会重新计算为零，一次修改最多切换一个阶段。

### 运行条件与故障处理

- 电脑需保持唤醒，浏览器保持运行，学校控制页保持打开。插件不是云端定时服务，不能在电脑休眠或浏览器关闭时保证执行。
- 同一标签页短暂刷新或认证跳转，可在有限期限内核验并接续；关闭页面、扩展更新／重载或浏览器会话结束后，需确认实际状态再手动开始。
- 自动切换前查询连续超时或返回 HTTP 502／503／504，且没有发送开关指令时，最多等待至**原定切换时间后 5 分钟**。首次失败结束后按 30、60、120、180、240 秒安排最多五轮重查；全部失败会提前停止，刷新不延长期限。恢复期间当前开／关状态可能多保持几分钟，可随时停止；操作网页原生开关或定时器会取消恢复。
- 查询每次最多等待 8 秒；开关请求最多等待 15 秒，均包含响应正文。整次操作最多 30 秒，上层取消或总期限先到时立即终止等待。已在恢复期限内发送的指令可在总期限内继续确认，结果未知仍不重发。
- v1.1.19 改善慢响应及短暂接口异常造成的停止，不能消除学校服务或网络故障。
- v1.1.20 在已发出的开关请求超时后，先停止循环，再立即和约 30 秒后分别只读查询实际状态与学校定时器；固定在超时后 45 秒结束，最多四次 GET，不重试、不重发开关、不自动接续。停止、手动操作插件或离开／刷新页面会取消核验。
- 核验结果补充到原报告，区分观察到目标状态、原状态、两轮变化或未知。即使观察到目标状态，也不能证明原指令执行成功或确定服务器内部原因；请自行确认状态后点击停止，再手动开始。
- 学校定时器冲突、实际状态与预期不符、关键存储失败等情况会停止循环。**已发出的开关指令如果结果未知，不自动重发，也不补发关机指令。**
- 浏览器调度和学校服务可能延迟。这不是精确到秒的定时器；学校接口变化也可能导致插件停止。

## 错误报告（可选）

无需指定作者电脑上的任何路径。每位用户可以使用自己的本地文件夹。

1. 在“自动循环”面板展开“说明”，打开“报告设置”；也可从扩展详情打开扩展选项。
2. 点击“选择报告目录”，新建或选择自己的文件夹（例如“文档”中的 `HKUST-AC-reports`），允许写入。
3. 之后报告会尝试自动保存；没有授权或写入失败时，会先缓存于插件内，不妨碍正常启动。缓存最多保留最近 20 个报告编号。

报告记录错误代码、请求耗时、循环状态、取消原因和恢复结果。不保存登录令牌、Cookie、账号资料、原始请求头或完整响应正文，也不会自动上传给作者。完整说明见 [PRIVACY.md](PRIVACY.md)。

v1.1.22 增加带证据引用的诊断摘要：列出事实、原因线索、缺失证据及建议，覆盖业务拒绝、网络、超时、格式、认证、状态冲突、调度、存储与通信问题。学校业务错误仅从固定字段提取最长 160 字符的短说明，过滤明显敏感信息；它仍是学校提供的线索，分享前请检查。HTTP 200 不代表业务成功，业务码 403 也不单独等于登录过期。

已发出但未确认的开关请求遇到业务拒绝、连接中断、格式错误或状态未确认时，也可复用两轮只读核验。最多四次 GET，固定 45 秒内结束；主动操作、页面离开或明确认证失效会取消或跳过。无论后续观察结果如何，都不重发指令、不自动接续。普通只读通信失败会提示状态读取失败，原有未知开关警告仍保留。

v1.1.21 在这类查询故障停止后保留最长 15 分钟的被动关联窗口，补充网页原生开关回执及定时器／实际状态查询。只观察网页已有请求，不增加探测，也不会据此自动恢复控制。手动开关成功仅能证明对应接口在那个时间可用，不能证明定时器接口正常或确定服务器内部原因。

需要反馈问题时，可在 [Issues](https://github.com/Chen13754/HKUST-AircCon-Automatic-repeat-switch/issues) 提供插件版本、浏览器版本、错误代码和操作步骤。报告包含时间与运行上下文，上传前请自行检查；不要提交学校登录信息或个人网页截图中的账号资料。

## 更新与卸载

**更新：**先停止循环并确认实际状态，再下载新版 ZIP。将新包中 `HKUST-AC-Cycle` 内的文件替换到原安装文件夹，在扩展管理页点击“重新加载”，然后刷新学校主页、手动开始。保留原安装文件夹有助于沿用设置；目录授权失效时重新选择报告目录。不要同时加载两份插件控制同一页面。

**卸载：**先停止循环并确认实际状态，再从扩展管理页移除。卸载不会替你关机；浏览器会删除扩展内部数据，已导出的报告文件仍留在你选择的目录。

## 常见问题

**提示找不到 manifest 或无法加载？** 先完整解压，再选择直接包含 `manifest.json` 的目录。不要选择 ZIP；如果下载了仓库源码，应选择里面的 `edge-extension`。

**学校网页没有出现面板？** 检查插件已启用，登录后回到 `/njggt/app/home` 并刷新；插件只在学校支持的页面工作。企业管理的浏览器可能限制开发者模式或扩展安装。

**点击扩展图标没有弹窗？** 这是正常的，请在学校空调状态卡片中操作。

**为什么更新后停止了？** 更新／重新加载会结束旧扩展会话，不会自动重建控制循环。确认实际状态后重新开始即可。

**会收集账号或上传日志吗？** 插件使用当前学校页面的登录状态向学校接口发送请求；没有作者的日志服务器或统计服务。诊断保存在本机，只有你主动分享才会发送给他人。

## 开发与打包

普通使用者无需执行以下命令。项目没有第三方运行依赖，测试需要支持 `node --test` 的 Node.js。

```powershell
cd edge-extension
node --test
cd ..
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

此命令的执行策略仅作用于该次 PowerShell 进程，不修改系统设置。打包脚本在项目 `dist/` 中生成版本 ZIP 和 SHA-256 校验文件，只收录明确列出的运行文件与公开文档。`dist/` 不进入 Git；下载包作为 GitHub Release 附件发布。可用 `Get-FileHash -Algorithm SHA256 <压缩包路径>` 与 Release 中的 `.sha256` 文件核对。

本地预览：`node ui-preview/server.mjs`，打开 `http://127.0.0.1:8798/njggt/app/home`。预览使用模拟数据，不连接学校，不控制空调。
